# 香盡

中式恐怖密室逃脫。中元夜，在祖父書齋裡的那炷香燒盡之前，找出離開的方法。

**線上遊玩：** https://easylive1989.github.io/chorror/

## 操作

- 拖曳畫面環顧四周，點擊物品調查
- 先在下方背包選取物品，再點擊目標即可使用
- 「提示」會給出下一步線索，但香會燒得更快

## 開發

```bash
npm install
npm run dev     # http://localhost:5179
npm run build   # 輸出到 dist/
```

以 Three.js 與 Vite 製作；材質、插圖與音效皆在瀏覽器中即時生成，沒有外部素材檔。
